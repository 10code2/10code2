## 📦 项目 / Projects

### 🚀 CloudLab — 基于 Docker 的多云服务云平台

在一台华为云服务器（2核2G）上，用 Docker 搭建的多服务自托管平台：

| 能力域 | 服务 | 说明 |
|---|---|---|
| 入口网关 | Nginx Proxy Manager | 反向代理、子域名分流、自动 HTTPS |
| 安全/密码 | Vaultwarden | 轻量密码管理 |
| 可用性监控 | Uptime Kuma | 服务探活、状态页 |
| 资源监控 | Prometheus + Grafana | 主机指标、可视化仪表盘 |
| 存储/文件 | Alist | 云盘、WebDAV |
| 内容/站点 | Halo | 个人博客 |
| 数据保护 | backup.sh | 定时备份配置与数据卷 |

> 过程中处理了**镜像加速、证书 DNS 验证、防火墙切换、ICP 备案、内存优化**等真实问题。
> 详见 👉 [MyCloud-Vault](https://github.com/10code2/MyCloud-Vault)
